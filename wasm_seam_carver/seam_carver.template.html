Seam carving in WebAssembly

The same C++ SeamCarver class as the Python modules in this repo, compiled to WebAssembly with Emscripten, or its line-by-line JavaScript port, which removes exactly the same seams. Two more engines compute the costs in parallel: a C++ version on several threads, and one on the GPU with WebGPU. With incremental cost updates, every engine recomputes after a seam only the costs that seam changed. Pick a picture, then choose how much narrower and lower it should get: the lowest-energy seams disappear while the content keeps its proportions. The height shrinks by turning the picture a quarter turn, removing vertical seams and turning it back.
