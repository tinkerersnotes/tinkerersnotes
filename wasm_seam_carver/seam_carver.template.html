Seam carving in WebAssembly

The same C++ SeamCarver class as the Python modules in this repo, compiled to WebAssembly with Emscripten, or its line-by-line JavaScript port, which removes exactly the same seams. Pick a picture, then choose how much narrower and lower it should get: the lowest-energy seams disappear while the content keeps its proportions. The height shrinks by turning the picture a quarter turn, removing vertical seams and turning it back.
