Demos and notebooks

Seam carving

Seam carving shrinks a picture by removing its cheapest paths of pixels, keeping what stands out. Both demos run in the browser, from the same seam carver as the Python modules in the repository.

Seam carver

Shrink a picture's width and height and compare engines: the C++ core in WebAssembly, its JavaScript port, C++ on several threads and WebGPU.

Seam carving terrain

The picture as a 3D landscape, raised by the cost of reaching each pixel. The cheapest seam crosses the ridge at its lowest pass. Carve and watch the terrain change.

Triangulation

Delaunay triangulation connects points into triangles whose circumcircles hold no other point. The demo runs a JavaScript port of the repository's divide and conquer triangulation.

Moving Delaunay triangulation

Up to 2000 points bounce around a box, triangulated from scratch every frame, with their convex hull. Choose how many, pause, or start them over.

A 3D convex hull and its projections

Points move in a box. Their convex hull is built every frame from two weighted Delaunay triangulations, and each coordinate plane shows, in relief, the side of the hull facing it.

Notebooks

The repository’s Jupyter notebooks. Google Colab runs one with a Google account; where Colab lacks something a notebook needs, its first cell fetches or installs it. GitHub shows a notebook’s code without running it, and without outputs, since they aren’t committed: plots appear only when a notebook runs.

  • Divide and conquer Delaunay triangulation

    Splits points by lines through their centre of mass, merges the halves with flips, and draws the result and its dual, the Voronoi diagram, for four point sets.

    Run in Colab · View on GitHub triangulation/divide_and_conquer.ipynb

  • Incremental Delaunay triangulation

    Inserts points one by one into a virtual triangle, finite or with its corners at infinity, and shows which triangles a finite one loses.

    Run in Colab · View on GitHub triangulation/incremental.ipynb

  • HNSW nearest neighbour search

    Builds Hierarchical Navigable Small World graphs, traces a query down their layers, compares the bottom layer with the Delaunay triangulation, and measures recall against work on synthetic data.

    Run in Colab · View on GitHub hnsw/hnsw.ipynb

  • Finding similar texts with MiniLM

    Turns the docstrings of Python’s standard library, numpy and matplotlib, and this repository’s notes, into vectors with a small transformer, then searches them by meaning with HNSW.

    Downloads the 90 MB MiniLM model from Hugging Face on its first run.

    Run in Colab · View on GitHub hnsw/minilm_search.ipynb

  • Seam carvers compared

    Times the pure Python, Cython, C++ and other seam carvers in the repository as more and more seams are removed.

    Needs the repository’s compiled modules, so it runs only in a local checkout, after ./init.sh.

    View on GitHub seam_carver.ipynb

  • Cython and ctypes

    Counts primes in Python and three Cython versions, and sorts with C’s qsort through ctypes, with timing plots.

    Run in Colab · View on GitHub cython_and_ctypes.ipynb

  • Memory-mapped files in Python

    Sorts a file’s bytes in place through numpy, grows a mapped file, and calls a function straight from a shared library mapped into memory.

    Run in Colab · View on GitHub python_mmap.ipynb

  • Correlated random samples

    Turns independent normal samples into correlated ones with the Cholesky factor of a correlation matrix, plotted in interactive 3D.

    Run in Colab · View on GitHub statistics_playground.ipynb
