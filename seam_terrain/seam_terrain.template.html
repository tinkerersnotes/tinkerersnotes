Seam carving terrain

Every pixel rises as high as the cost of the cheapest seam from the top row down to it, computed by the JavaScript port of this repo's SeamCarver. Below the bottom row the picture continues mirrored, so the bottom row becomes a ridge between two valleys. A seam only climbs, so any path from one valley to the other reaches at least the ridge's height where it crosses: the cheapest seam, in red, crosses at the ridge's lowest point, the mountain pass. Carve to remove seams one by one: each removes the pass, the terrain settles and the next cheapest seam finds another way over the ridge. The height shrinks by turning the picture a quarter turn and removing the same seams: that terrain rises from left to right, with the ridge on the right. Whichever way you carve comes last: carving the width after the height carves the height again first, then the width on top.
